\chapter{How much confidence belongs beside an interaction?}\label{ch:uncertainty}

Exact laws can be evaluated with uncertain inputs. This does not weaken the law; it determines the uncertainty of the resulting number. We derive the propagation rules for a coalition contrast, including shared baselines and common calibration, so that the mathematical account remains precise when its physical inputs are estimated.


\section{Exact subtraction is not exact observation}
A Möbius coefficient is an exact signed sum of its input table. If the inputs are estimated, the coefficient is estimated too. Alternating signs do not automatically cancel measurement errors, and a shared baseline can create correlations that must be retained.

This matters especially at high order. A genuine signal may shrink as the $k$th power of a small action amplitude while the contrast still combines $2^k$ noisy readings. A theorem can be exact and its empirical target difficult to resolve. The resulting distinction is precise: algebra determines the target and its error propagation, while a measurement procedure determines the distribution of the inputs.

\section{A linear contrast has a complete covariance formula}
Collect the required estimates into a vector $\widehat e$ and let $c_S=(-1)^{|T|-|S|}$. Then $\widehat m=c^{\mathsf T}\widehat e$. If the estimates have finite covariance matrix $C$, elementary bilinearity gives
\begin{equation}\label{eq:variance}
 \operatorname{Var}(\widehat m)=c^{\mathsf T}Cc.
\end{equation}
This is exact for the specified linear contrast, whether or not the errors are Gaussian. It includes variances on the diagonal and pairwise error covariances off the diagonal.

\begin{proof}
Subtract the mean from each estimate and expand the square of $\sum_S c_S(\widehat e_S-\mathbb E\widehat e_S)$. Taking expectations gives $\sum_{S,R}c_Sc_R\operatorname{Cov}(\widehat e_S,\widehat e_R)$, which is the matrix expression.
\end{proof}

For independent equal-variance readings of all $2^k$ potentials, each with variance $\sigma^2$, the corresponding alternating potential contrast has variance $2^k\sigma^2$. Independence is an assumption about errors, not a property supplied by the transform.

\section{Why the shared baseline does not simply disappear}
For a normalized triple table, $E(\varnothing)=0$ is exact. The seven nonempty values may be calculated as $\widehat E(S)=\widehat V_0-\widehat V_S$, all using the same estimated baseline potential. If one treats these seven estimates as independent, one ignores their shared error.

The signed coefficients of the seven nonempty rows sum to one. Therefore the baseline estimate enters the triple contrast once. If the eight potential estimates are mutually independent with equal variance $\sigma^2$, the result has variance $8\sigma^2$: one baseline contribution and seven endpoint contributions.

Equivalently, each nonempty $\widehat E(S)$ has variance $2\sigma^2$, and two different rows have covariance $\sigma^2$ through the baseline. Substituting this full covariance into Equation~\ref{eq:variance} again gives $8\sigma^2$. It is not $14\sigma^2$, obtained by incorrectly treating those differences as independent, and not $7\sigma^2$, which would describe seven independently measured E-values of variance $\sigma^2$ under a different design.

\begin{cautionbox}{What cancels, and what does not}
A deterministic constant added to every table entry cancels in a nonempty difference. An uncertain baseline reused inside normalized differences can leave a correlated error contribution. These statements concern different data-generating constructions.
\end{cautionbox}

\section{Shared calibration creates further dependence}
All endpoints can use the same estimated reference, temperature, Hessian or response parameter. A common parameter error can therefore move several table entries together. In the feedback example, uncertainty in $\nu$ or $\tau$ changes the generated endpoints across the whole coalition table; it is not a new independent error for each row.

If $m=f(\eta)$ is differentiable in a parameter vector and a first-order approximation is appropriate, the delta method gives
\begin{equation}
 \operatorname{Var}(\widehat m)\approx
 \nabla f(\eta)^{\mathsf T}\operatorname{Cov}(\widehat\eta)\nabla f(\eta).
\end{equation}
This approximation has a different status from the exact linear-contrast identity $c^{\mathsf T}Cc$. The latter is exact once the covariance of the table estimates is specified; the delta method approximates how parameter uncertainty produces that covariance or the coefficient's variance.

For log-density inputs, small densities can magnify relative error. A finite-bin probability is an integral over a region, whereas a point density is relative to a measure at a point. Their uncertainty and bias refer to different targets. Keeping the target explicit preserves the canonical identity's meaning without turning a numerical estimate into a different theorem.

\section{What a nonzero triple can establish}
Within an exactly specified model, affine response and quadratic valuation imply a zero triple. A mathematically nonzero triple in its endpoint table disproves the conjunction of those premises for that table. It does not select a unique alternative mechanism.

With estimated inputs, the contrast additionally carries the error distribution just derived. A departure from zero must be interpreted relative to that uncertainty. Potential nonlinearity, response nonlinearity, changing baselines and a mismatched field are distinct explanations of the same apparent discrepancy.

A zero can likewise arise from the structural degree ceiling or from cancellation in a nonlinear composite. The square-root response of Chapter~\ref{ch:composite} demonstrates exact cancellation. Thus the theorem's logical subject remains the complete set of assumptions, not a claim that every zero implies simple physics or every triple implies oscillation.

\section{A deterministic error bound}
Error bounds can also be stated without a probability model. If each input satisfies $|\widehat e_S-e_S|\leq\epsilon_S$, the triangle inequality gives
\begin{equation}\label{eq:deterministic-contrast-error}
 |\widehat m-m|\leq\sum_{S\subseteq T}|c_S|\epsilon_S
 =\sum_{S\subseteq T}\epsilon_S.
\end{equation}
The bound is conservative because it allows all errors to align with the contrast signs. Covariance information can give a more informative probabilistic description, but it is not needed for this deterministic guarantee.

A structural zero has a further advantage: it removes terms by proof rather than by an uncertain estimate. Factor support and degree ceilings therefore reduce both computational and informational demands. For EBU, this encourages the simplest account that is exact under the declared model, with explicit error bounds wherever approximations enter.

\section{Communicating a result people can challenge}
An interaction record identifies the group, baseline, field, endpoint table and coefficient. When inputs are estimated, it also identifies their uncertainty and dependence. This connects the mathematical result to the information used to evaluate it.

The resulting account is more useful to communities because disagreements can be located. A challenge to a sensor reading differs from a challenge to the reference, and both differ from a challenge to an allocation rule. Error propagation preserves those distinctions instead of hiding them inside a single authoritative-looking score.

We now have the tools to join the theory in one place: exact endpoint laws, generated response, finite interaction, canonical probability and uncertainty each connect to the same declared comparison.
