The object under review:

```
z = xⁿ + Δt u(xⁿ)                       (frozen no-action successor)

Δe(q) = V_loc(z) − V_loc(z + Δt S_e q) − C_a(q)
      = v_i(z_i) + v_j(z_j) − v_i(z_i − Δt q) − v_j(z_j + Δt η q) − C_a(q)
```

for one accepted edge action `i → j`, `q ∈ [0, q_acc]`, quoted before

## A. Locality

**Verified derivation (with exact scope).** Write the global functional as
`V(x) = Σ_k v_k(x_k)` — the **separability assumption**: (i) `V` is a sum of
per-cell terms; (ii) each term is a function of that one cell's state only.
The action changes only the coordinates `i` and `j`
(`(S_e)_k = 0` for `k ∉ {i,j}`), so for every unaffected `k` the term
`v_k(z_k)` appears identically in `V(z)` and `V(z + Δt S_e q)` and cancels
**exactly**:

```
V(z) − V(z + Δt S_e q) = Σ_{k∈{i,j}} [ v_k(z_k) − v_k((z + Δt S_e q)_k) ]
                        = V_loc(z) − V_loc(z + Δt S_e q).
```

The reduction is an identity, not an approximation, and holds for any
(convex or not) per-cell `v_k`. Both current functional families satisfy the
assumption (`d0_v29.penalty` is per-cell; `V_total` is `fsum` of per-cell
terms).

**What fails with nonlocal coupling.** If `V` contains a cross term
`w(x_p, x_r)` with `{p,r} ⊄ {i,j}` but `{p,r} ∩ {i,j} ≠ ∅`, the difference
acquires a term depending on the state of an unaffected cell — the quote
would need `x_p` or `x_r` outside the permitted view, violating the §4.2/§4.3
information boundary. Three sub-cases, stated precisely:

1. cross terms **entirely inside** the affected set (`w(x_i, x_j)`): the
   reduction still holds with `V_loc` extended by `w` — local, but no longer
   per-cell separable;
2. cross terms **straddling** the affected boundary: reduction fails; the
   exact difference is non-local. Such a functional is **inadmissible** for
   the quote law as specified;
3. edge-state or path-dependent terms (no cell-state argument): outside the
   present state-functional formalism entirely (V2.7 already keeps transport
   dissipation in `Ψ`, not in `V_state`).

**Verdict A: verified**, with the admissibility condition (per-cell
separability, or at worst affected-set-contained coupling) stated as an
explicit assumption any future functional extension (e.g. the §7.4 capacity
coordinate `k_i`, which is per-cell and therefore admissible) must preserve.

## B. Dimensional consistency

**Verified derivation.** With `[x] = stock`, `[q] = stock·time⁻¹`,
`[Δt] = time`: `[Δt q] = stock` (a valid argument shift of `v`); `[v] = B`
(the declared burden unit of the resource account); `[μ] = [v'] = B·stock⁻¹`;
`[Δt q μ] = B`; `[C_a] = B` (required by declaration, Def 6.4). The exact
and linear forms are homogeneous in `B`. ✓

**Confirmed:** one EBU is currently a **calibrated unit of
resource-account-specific burden reduction** — the unit of the declared
functional `v` for that account. It is **not** a joule, not a stock unit,
not an hour of labour, and not a currency unit. It acquires an energy- or
stock-equivalent reading only through the declared calibration of the
weights (`α, β, χ, λ_L, c₀`), which is a per-account design declaration;
cross-account comparability does not exist absent a separately justified
conversion law (foundation §13, review Observation 10.1 — both consistent).

**Verdict B: verified.**

## C. Exact versus linear quote

**Verified derivation.** Let
`ψ(q) = v_i(z_i − Δt q) + v_j(z_j + Δt η q)`. Then
`ψ'(0) = −Δt v_i'(z_i) + Δt η v_j'(z_j) = −Δt (μ_i(z_i) − η μ_j(z_j))
= −Δt f_e(z)` — the quote's tangent at zero is exactly the V2.8 loss-aware
force (Def 2.3), independently re-derived. Hence

```
Δe_linear(q) = Δt q ( μ_i(z_i) − η μ_j(z_j) ) − C_a(q).
```

**Theorem (tangent bound; re-proved).** For convex `v_i, v_j` and all
`q ≥ 0`: `Δe(q) ≤ Δe_linear(q)`, with equality iff `ψ` is affine on
`[0, q]`. *Proof.* `ψ` is convex (convex ∘ affine, summed), so
`ψ(q) ≥ ψ(0) + q ψ'(0)`; rearrange and subtract the common `C_a(q)`. ∎
Numerically re-checked on a 240-case sweep across deficit, band, excess, and
reserve branches with `η ∈ {0.5, 0.9, 1.0}`: zero violations.

**Confirmed: the exact finite difference must define settlement.** Two
independent failure modes of the linear form, both reproduced numerically:
on an active branch it over-credits without bound in `q` (E1: linear
`+15.18` vs exact `+7.94`); on the flat band it prices a large damaging move
at only `−C_a` (E2: linear `−0.08` vs exact `−5.52`). Either would be a
usable accounting exploit. The linear form is admissible only as a
diagnostic. The path-integral identity
`∫₀^q Δt f_e(z + Δt S_e s) ds = ψ(0) − ψ(q)` was also re-verified: "exact"
and "integral" coincide for a single action, so no third settlement form
exists to choose.

**Verdict C: verified.**

## D. Schedule concavity

**Verified derivation (post-Gate-0.1 statement).** `q ↦ V_loc(z) − ψ(q)` is
concave for convex `v` on any interval. Concavity of the **full schedule**
`Δe(q)` requires exactly the four conditions the gate names, and they are
all now present in the draft (Gate-0.1 corrected Theorem 6.9):

1. `V_loc` convex **along the action path** (each `v` convex; the path is
   affine in `q`, so this is per-cell convexity);
2. `C_a` **convex** on the interval (non-negativity alone is insufficient —
   the pre-0.1 wording had this gap; the 0.1 correction is confirmed
   correct);
3. `C_a(0) = 0` (anchors the zero-action point; without it Q1 fails and the
   schedule's left endpoint is mispriced);
4. a **declared permitted interval** `[0, q_acc]` (concavity is claimed on
   the committed domain only; `q_acc` comes from P1C, so the domain is part
   of the precommitment).

**Fixed activation cost `c₀·1[q>0]`, re-checked.** This `C_a` component is
not convex at `q = 0`: it is discontinuous there (midpoint test between
`q = 0` and `q = 2ε` gives `c₀ ≰ c₀/2`). Numerically: schedule value `0` at
`q = 0`, `≈ −c₀` at `q = 0⁺`, concave thereafter (2000-sample midpoint test
on `(0, q_acc]`: zero violations). So the correct statement — as the draft
now says — is concavity on `(0, q_acc]` with a downward jump at `0⁺`, not
concavity on the closed interval. The tangent bound of §C is unaffected.
One consequence worth registering for implementation: any schedule
*representation* (piecewise polynomial) must carry the `q = 0` point
separately from the `q → 0⁺` limit.

**Verdict D: verified as corrected at Gate 0.1; no further defect.**

## E. Action-cost double counting

This is the one place the foundation draft is materially **under-specified**
(not wrong, but silent), and the review's main finding.

**What `C_a` represents.** The physical transition `z → z + Δt S_e q`
already encodes the state consequences of the action, **including the
transport loss**: the source loses the full `q` while the destination gains
only `η q`. Therefore every burden that is a function of the realised cell
states — the destination's smaller relief, the source's drawdown, a reserve
term activating — is **already inside** the `V_loc` difference. Subtracting
it again through `C_a` would count it twice.

**Classification of candidate cost terms (as the gate requires):**

1. **Burden already represented in the field/state transition** — the
   `(1−η)q` shortfall *as experienced by the endpoint states*, source
   depletion of a regenerative or finite stock, reserve-term activation.
   **Must NOT appear in `C_a`.** (Source-depletion charges belong to the
   state functional now, and to the future debt layer `D_r` for
   finite/irreversible stocks — never to `C_a`.)
2. **Additional local burden not represented in the state transition** —
   burden whose physical carrier has **no state coordinate** in `V_loc`'s
   arguments: the dissipated stock itself priced as process burden
   (`λ_L·Δt(1−η)q` — the state vector has no "destroyed stock" coordinate,
   so pricing the destruction is not a state-difference double count),
   activation work `c₀`, wear on unmodelled equipment. **May appear in
   `C_a` if declared.** This is the V2.5 precedent (`λ_L·loss` debited on
   top of the live burden change).
3. **Monetary or labour cost** — Store-C economics. **Must NOT silently
   become physical EBU cost**; one hour of work or one unit of currency is
   not a burden unit (foundation §7.2-of-alignment-draft precedent: not one
   hour = one EBU).
4. **Audit/security penalties** — protocol-violation consequences. Belong to
   the settlement/violation layer (layer 5), **never inside the quote
   equation** (they would make the quote depend on conduct, not physics).

**No-double-count condition (stated for adoption).**

> `C_a` may contain only burden terms whose physical carrier is **not** a
> state coordinate appearing in the arguments of `V_loc` in either compared
> state. Equivalently: if a burden can be expressed as
> `V_loc(z) − V_loc(z + Δt S_e q)` under the declared (or any admissible
> extended) state functional, it is a **field** burden and must be priced
> only there; `C_a` prices the **action process**, never the state
> consequence.

Operational test (preregistered as validation group Q19): construct a
fixture where a state-carried burden (e.g. the destination shortfall due to
`η < 1`) is deliberately also inserted into `C_a`; the audit reference must
detect that the same physical quantity is priced twice.

**Correction required (narrow, wording/scope — recorded, not applied).**
The foundation draft's Def 6.4 gloss "transport dissipation priced into
burden units" is legitimate only under the category-2 reading (pricing the
destroyed stock as process burden). The draft should, at its next authorised
amendment: (i) state the no-double-count condition above; (ii) label the
`λ_L` term explicitly as category 2; (iii) forbid categories 1, 3, 4 in
`C_a`. This does not change the central equation — `C_a` is a declared
input, and the condition constrains its declaration.

**Verdict E: correction required (narrow).**

## F. Natural-drive separation

**Verified derivation.** Re-proved from scratch: (i) with `C_a(0) = 0`,
`Δe(0) = V_loc(z) − V_loc(z) = 0` for every drive — an idle actor quotes
exactly zero; (ii) the same `z` appears in minuend and subtrahend, so the
drive's own burden change `δ = V_loc(z) − V_loc(x^n)` cancels identically;
the "naive" pre-tick-baseline rule differs by exactly `−δ_loc`
(re-derived; matches the V2.5 guarded-vs-naive test structure and the
foundation's Proposition 7.1). The regeneration worked check (logistic
`g = 2` at `x = 10`, `z = 12`, idle quote `0`) reproduces.

**Limits, all confirmed as stated in the draft (post-0.1):**

- the cancellation is strictly **per-tick**: the proposition says nothing
  about an action's influence on *future* drives;
- **persistent capacity modification is not yet priced** — correctly held
  open (O1) with the per-cell capacity-coordinate proposal as the candidate
  carrier (admissible under §A's separability condition);
- **changing drive during a long action** requires either a new quote epoch
  per tick (the draft's protocol restriction: actions complete within their
  quoted tick; longer processes are per-tick quote sequences) or additional
  present local state; the draft chose the epoch route — consistent with
  §I below.

**Verdict F: verified.**

## G. Telescoping and closed cycles

**Re-derived independently.** With `z^n = x^n + Δt u(x^n)`,
`x^{n+1} = z^n + Δt S_n q_n`, `δ^n = V(z^n) − V(x^n)`:

```
Σ Δe_n = Σ [V(z^n) − V(x^{n+1}) − C_n]
       = Σ [V(x^n) − V(x^{n+1})] + Σ δ^n − Σ C_n
       = V(x⁰) − V(x^N) + Σ δ^n − Σ C_n            (driven, exact identity)
```

undriven (`u ≡ 0` on affected cells ⇒ `δ^n = 0`):
`Σ Δe_n = V(x⁰) − V(x^N) − Σ C_n`; closed cycle `x^N = x⁰` ⇒ `−Σ C_n ≤ 0`.
The driven identity was re-verified numerically to machine precision on
random driven sequences (it is an identity, not a bound).

**Assumption audit (each checked against the draft's T1–T6):**

| assumption | present in draft? | audit note |
|---|---|---|
| fixed functional | T1 ✓ | same `v` for damage and repair — the single-equation principle; without it, arbitrage (draft §8.3 table) |
| fixed parameters | T1 ✓ | includes `R_eff`; re-certification must close an accounting epoch (draft O6; consistent) |
| non-negative action cost | T5 ✓ (Def 6.4) | `C < 0` is a subsidy breaking the cycle bound — confirmed |
| one sequential action per **overlapping affected cell set** | T3 + Gate-0.1 remark ✓ | the remark is correct: disjoint simultaneous actions commute by separability (§A); only shared-cell simultaneity needs §K |
| no duplicated settlement | T6 ✓ | audit-layer duty |
| unchanged quote rules | T5 ✓ | no re-quoting/rewriting |
| non-negative lower bound for total issuance | Gate-0.1 corrected Cor 8.3 ✓ | `V ≥ 0` now explicit; true for the declared family (sums of squares); correctly noted vacuous otherwise |

**Verdict G: verified (with the Gate-0.1 corrections in place; no further
defect found).** The driven residual `Σ δ^n` and its exploit surface
(self-induced drive amplification; V2.6 seed-0 as witness) are correctly
held open (O2) and are exactly what validation group Q22 attacks.

## H. P1C orthogonality

**Verified against `p1c_v29.py`.** P1C decides physical permission
(classification, aggregate budget, σ-scaling) with no valuation input; the
quote evaluates the **accepted** quantity (`q_acc`), so its schedule domain
is `[0, q_acc]` — a positive quote over a P1C-rejected or rationed quantity
cannot exist, hence cannot authorise anything (draft Obs 11.1, confirmed).
A P1C-permitted action can be quoted negative (E2-type; draft Obs 11.2,
confirmed). Both directions of non-implication hold.

**Byte-identity requirement.** Because the quote module is specified as a
pure observational function (no mutation of `x`, no influence on `q_acc`),
adding it to a P1C run must leave the physical trajectory **byte-identical**
— the V3.0 analogue of V2.5's `selection="physics"` observational identity
(`test_v25.test_observational_identity`, exact tuple equality, no rounding).
This is a design requirement to be *validated*, not assumed (group Q17); the
non-binding case (σ = 1) additionally checks the quote layer does not perturb
the D0-compatible path already tested by `test_v29_p1c.py` group 9.

**Verdict H: verified as design; validation deferred to Q17 as it must be.**

## I. Quote epochs and rejection

**Analysis of the sequence** proposal → P1C allocation → quote → acceptance →
execution. The hazard: actor `b` rejects after the aggregate σ was computed
with `b`'s request included. Options: (a) leave all other allocations
unchanged; (b) re-allocate the freed budget within the tick.

**Resolution registered (consistent with the draft, formalised here).**

- **First model adopts (a): no intra-tick reallocation.** All other actors'
  `q_acc` and committed schedules remain exactly valid; the freed budget is
  simply unused this tick. This is conservative in the only direction that
  matters physically (aggregate export can only fall below the budget —
  preservation-safe) and quote-safe (no actor's accepted quantity changes
  under an old schedule). The draft already states this (§11); confirmed
  sound.
- **If any design ever re-allocates (option b), it must open a new quote
  epoch:** an epoch identifier binds every committed schedule to one
  allocation pass; a reallocation invalidates **all** quotes of the old
  epoch for that source group and requires new accepted quantities and new
  committed schedules for **every** affected action before execution. A
  rejected action must never silently cause another actor to receive a
  different quantity under an old quote.

**Candidate design (epoch semantics, registered for Gate 1B):** every
schedule commits `(tick, source_id, epoch_counter, allocation_inputs_hash)`;
settlement requires the executed epoch to equal the committed epoch;
mismatch ⇒ the quote is void and a violation record is emitted. Validation
group Q20 tests exactly this.

**Verdict I: resolved for the first model; epoch formalism registered.**

## J. Measurement mismatch

Three cases:

1. **`q_meas = q_acc`** — settle at the committed endpoint. Sound.
2. **`0 ≤ q_meas < q_acc`** — settle at `Δe(q_meas)`, a point of the
   precommitted exact schedule. Sound, and safe for the reasons the
   Gate-0.1 correction states (precommitment + exact evaluation at the
   measured point + no post-outcome rule), **not** because of concavity.
3. **`q_meas > q_acc`** — **the committed schedule does not extend beyond
   `q_acc`, and no settlement semantics currently exist. This is open and
   is registered as such (new Open problem O8), not solved.** The physical
   event is simultaneously a P1C violation (export beyond the accepted
   allocation — potentially beyond the preservation budget, feeding
   `O_physical` and, in the future architecture, ecological debt) and a
   quote-protocol violation. **Minimum safety envelope frozen for any later
   design:** (i) **no positive credit under any circumstances** — a
   positive quote is never silently extended beyond the physically accepted
   quantity; (ii) a **protocol-violation record is mandatory**; (iii) the
   physical overdraw is reported to the physical/debt layer, not absorbed
   by the wallet; (iv) if a *debit* schedule for the overrun is ever
   proposed, it must itself have been **committed before execution** —
   an after-the-fact debit formula is the same defect as an after-the-fact
   credit formula. Whether overexecution settles at `Δe(q_acc)` capped to
   `≤ 0`, at zero credit plus a separately committed debit, or voids the
   whole transaction, is **not decided here**. Validation group Q9 tests
   only the frozen envelope.

**Verdict J: cases 1–2 verified; case 3 open (O8) with a frozen minimum
envelope. No claim of resolution is made.**

## K. Shared-source splitting

**Counterexample independently re-verified.** `α = β = 1`, `L = 4`,
`U = 16`, `η = 1`, `u ≡ 0`, `C ≡ 0`; source `x_i = 18` (`v = 4`), sink
`x_j = 0` (`v = 16`); two actors, each accepted `q = 2` on the same edge:
independent frozen quotes `= 16` each (sum `32`); true joint change `= 20`;
phantom credit `12`. Reproduced exactly by fresh code. The convexity
mechanism (monotone increments) is confirmed: independent same-baseline
quotes over-credit the credit side and under-charge the damage side on any
shared cell.

**First-model restriction reviewed:** one action per source per micro-step
for overlapping local support — sound, minimal, and sufficient for
Theorem 8.2 as stated (with the Gate-0.1 disjointness remark). Confirmed
appropriate as the production rule for Gate 1.

**Proposed extension reviewed (aggregate source-group quote):**
conservativity holds *by construction* (the group settles the true joint
difference); proportional attribution is linear in `q_acc`, hence
same-edge split-invariant and order-invariant on the frozen aggregate;
information needs are source-local (the same data P1C's σ already touches).
**Request-inflation risk is real and open:** shares are proportional to
`q_acc` while the joint value is concave in the aggregate, so inflating
one's request can shift share; whether it is profitable net of the
inflater's own physical execution duty is unresolved (draft O3). **The
extension is NOT promoted to a theorem** — correctly registered as a
candidate; this review finds no proof and supplies none.

**Verdict K: verified; restriction adopted; extension remains candidate.**

## L. Actor-layer boundary

**Confirmed.** The Gate-1 quote inputs (draft §4.2) contain no needs,
health, wallet, death, transfer, or fairness objects; §19 registers those
for Gates 2–4 only, and §19.1's health update reads unmet physical need,
never wallet state. The quote is a function of frozen field data, the
declared action, `q_acc`, `C_a`, and certified constants — nothing else.
The information-boundary validation (group Q18) must poison-test wallets,
health, and prices explicitly so the boundary is enforced by test, not by
intention. No contamination found in the design.

**Verdict L: verified.**

## Overall verdict

> **PASS WITH CORRECTIONS** — all corrections are narrow wording/scope
> items; **no material defect was found in the central quote equation, the
> P1C ordering, or the scientific meaning of EBU.** Preregistration may
> proceed.

Required corrections (recorded here; the foundation draft is deliberately
not modified in this gate):

1. **(E) No-double-count condition for `C_a`** — adopt the condition and the
   four-way cost classification at the next authorised amendment of the
   foundation draft; label the `λ_L` term category 2; forbid categories
   1/3/4 in `C_a`. Until then, Gate-1B implementation must treat the
   condition as normative (validation group Q19).
2. **(I) Quote-epoch semantics** — the no-intra-tick-reallocation rule is
   already in the draft; the epoch identifier/invalidations formalism
   registered here should be added at the next amendment (validated by
   Q20 regardless).
3. **(J) Overexecution settlement (O8)** — register the open problem and the
   frozen minimum envelope (no positive credit; mandatory violation record;
   overdraw to the physical layer; any debit schedule precommitted). Q9
   tests the envelope only.
4. **(D, minor)** schedule representations must carry `q = 0` separately
   from the `q → 0⁺` limit when `c₀ > 0` (implementation note).

Non-claims of this review: it does not prove the quote law is
incentive-compatible against coalitions (O2/O3 open; V2.6 seed-0
unresolved); it does not validate any implementation (none exists); its
numerical re-checks are validation of derivations at chosen points, never
proof; it does not close any inherited open problem.
