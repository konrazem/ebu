## 1. Conventions

Status vocabulary:

- `FOUNDATION_RESOLVED_PROSPECTIVELY`: fixed by F1-F16 if the package is
  independently accepted;
- `RESOLVED_UNDER_ASSUMPTIONS`: a conditional theorem or existing accepted
  limited result, not a universal result;
- `SUPERSEDED_FORMULATION`: removed as an active question but retained in
  historical trace;
- `OPEN_FOUNDATION_DECISION`: requires later prospective authority;
- `OPEN_SCIENTIFIC_MODEL`: requires mathematical/model closure;
- `OPEN_SCIENTIFIC_EMPIRICAL`: requires a preregistered identification or
  discrimination protocol and evidence;
- `OPEN_MIXED`: contains scientific and institutional components that must be
  separated;
- `OPEN_INSTITUTIONAL_SOCIAL`: cannot be selected by physical mathematics.
- `OUTSIDE_ACTIVE_AND_FUTURE_PROGRAMME`: not solved and not assigned to any
  active or future book, framework, implementation, experimental, or stage
  obligation by this package.
- `EXCLUDED_CONCEPT_NOT_OPEN_PROBLEM`: removed from the programme rather than
  retained as a solved or open scientific question; no future route or
  obligation is reserved.

Gate columns use `Y` for unconditional blocker, `N` for not a blocker when
retained explicitly, and `Dep` for a blocker only to a dependent declaration,
execution, claim, or book conclusion:

- `A`: atomic authority acceptance;
- `D`: atomic framework declarations;
- `4`: Framework I-4;
- `alpha`: non-atomic framework alpha;
- `X`: dependent scientific execution or claim;
- `B`: dependent book conclusion or regeneration.

The tables describe the post-acceptance state. Until independent authority
audit accepts the package, F1-F16 remain candidate decisions and the present
package does not self-close Gate `A`.
