## Code reuse vocabulary

- **Preserve historical:** `d0_v29.py`, `p1c_v29.py`, `ebu_quote_v30.py`,
  historical runners, serializers, tests and paper generators.
- **Do not reuse unchanged as a Gaussian engine:** `ebu_test_world.py`,
  `ebu_test_settlement.py`, `ebu_test_protocol.py`,
  `ebu_candidate_controllers.py`, `longhorizon_v30.py`.
- **Review for selective reuse:** immutable state concepts, deterministic
  hashing, exact arithmetic helpers, support declarations, receipts and
  conservation typing. A reusable idea is not permission to import its entire
  old protocol.
- **Source-lock existing off-branch core:** state/actions, generic distortion
  declarations, provenance, information contracts, ledgers, settlement
  separation and RNG arithmetic. See the
  [framework audit](LOCAL_GAUSSIAN_EBU_FRAMEWORK_DECISION.md).
- **Not implemented:** Gaussian potential evaluator, nature-first event
  profile, owner balances, random-affordable execution and Stage A/B runners.

## Cleanup means preservation plus clear routing

No model file, result, PDF, branch or tag is deleted. No broad file moves are
performed: old imports and historical reproduction paths remain intact.
Ignored caches are left untouched and must not be mistaken for tracked source.
An old root filename is not made authoritative merely by remaining present;
use the current index and its explicit supersession scope.

The checkpoint inventory is intentionally immutable. If an allowed document
receives a navigation banner, validation checks that removing that exact
banner restores the checkpoint bytes, except the explicitly recorded addition
of a missing final newline in `test_design.md`. README and the future register have
byte-identical archived baselines. All other checkpoint paths must remain
byte-identical. This proves preservation, not scientific correctness.
