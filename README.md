# EBU — physical action accounting and an open research programme

EBU studies how declared physical changes can be evaluated against explicitly
chosen functional reference conditions. **EBU calculates; actors choose.**
A value equation is not, by itself, a controller or a promise of homeostasis.

## The current direction

The prospective Local Gaussian programme uses one homogeneous conserved
resource and a declared local quadratic reference potential:

\[
V(x)=\frac12\sum_i\left(\frac{x_i-x_i^\star}{\sigma_i}\right)^2,
\qquad \sigma_i>0.
\]

For a finite physical action/group, the exact value is the potential decrease
less any separately declared physical process burden not already counted:

\[
E_G=V_{\mathrm{loc}}(z)-V_{\mathrm{loc}}(z+\delta_G)-C_G.
\]

The first proposed ideal model is lossless with \(C_G=0\). It separates physical
feasibility, valuation, proposed capacity affordability, random actor choice,
execution and audit. It does not hide a value-maximizing selector or natural
mean-reverting force inside EBU. Simultaneous groups remain in scope.

Gaussian reference geometry, signed capacity accounts and their proposed
stochastic dynamics are **not yet validated science**. Their intended tests
are a single-shock stage followed, only with separate approval, by a
continuously driven stage. Recovery, cycling, refusal and adverse comparisons
remain legitimate possibilities.

## Books

Book I is being restructured as an introduction: monetary and ecological
motivation, scarcity and access, homeostasis, functional balance, reference
geometry, potential, marginal field, finite action and the EBU equation.
Its definitions and conditional mathematics need not wait for experiments.
Claims about beneficial dynamics do.

The existing Parts II and III, all three supplied PDFs, historical proofs and
historical evidence remain preserved. The current work ends at architecture
and source reconciliation: **no new book has been generated**.

## What already exists

This repository contains historical D0/P1C models, finite EBU quote code,
preservation tests and committed results. In particular,
[Gate 1D-C](results/v3.0/gate1dc/MANIFEST.md) is finalized historical evidence:
30 registered runs under its own frozen design. It is not a result for the
new Gaussian model. D5 records software performance, not scientific outcomes.

Claude's prospective conservative-world harness and C0–C4 drafts were preserved
in a local checkpoint. Their code remains readable but is not the active
Gaussian design. N/H/X, Direction C and old service-first planning are
superseded or parked; they are not silently deleted or relabelled.

A generic framework exists on other Git lineages. The source-inspected
decision is F2: reuse appropriate infrastructure and later adapt the
scientific layer. This checkout does not yet contain a runnable Gaussian
framework. See the [exact baseline comparison](GAUSSIAN_EBU_BASELINE_DECISION.md).

## Safe navigation and reproduction

Read the relevant historical manifest and frozen protocol before reproducing
a historical result. Existing experiment scripts and some test suites advance
model state. **Do not treat the full CI workflow as static-only**, and do not
run a legacy command merely because it appears in an archived README.

Current authorization ends before model execution, AWS, manuscript generation
and publication. No automatic transition to a later stage is permitted.

The [preserved earlier README](docs/history/README_PRE_GAUSSIAN.md) contains the
historical version narrative and commands, under their original scope.
The [history index](docs/history/README.md) preserves all three inspected book
planning lineages. [AGENTS.md](AGENTS.md) governs scientific integrity,
reproducibility and authorization boundaries.

EBU is a research proposal, not an established replacement for money, a claim
that existing economies have no regulators, or proof that one scalar measures
all human and ecological value.
