## 3. Root cause

The committed runner (at `35a850f7`) performed a naive substring check:

```python
for fname in ("o14_v30.py", "exp_v30_o14.py"):
    src = open(fname).read()
    if "import random" in src or "import secrets" in src:
        _fatal(f"{fname} imports a randomness module")
```

The string literals `"import random"` and `"import secrets"` appear in the
guard's own source line inside `exp_v30_o14.py`. Reading
`exp_v30_o14.py` therefore always matched the guard's own literals, so the
preflight could **never** pass: the runner rejected itself unconditionally.
Independent read-only reproduction confirmed the self-match
(`o14_v30.py`: no substring hit; `exp_v30_o14.py`: hit on the guard line
only), and AST inspection confirmed that **neither production file actually
imports `random` or `secrets`** (root modules of all `ast.Import` /
`ast.ImportFrom` nodes checked).

## 6. Exact correction (runner)

`exp_v30_o14.py` — integrity checking only; no float, world, parameter,
certificate, timestep, run identifier/ordering, arm, candidate menu,
selector, physics, settlement behavior, output schema, summary rule,
hypothesis, falsifier, serialization rule, result path, or execution
command changed:

1. Added `import ast` (standard library).
2. Added module constants `_RANDOMNESS_MODULES = frozenset(("random",
   "secrets"))` and `_RANDOMNESS_GUARDED_SOURCES = ("o14_v30.py",
   "exp_v30_o14.py")`, and the helper `_randomness_imports(fname)`: parses
   the source with `ast.parse`, inspects `ast.Import` and `ast.ImportFrom`
   nodes (aliases included), normalizes every imported name to its root
   module, and returns the actual `random`/`secrets` imports. Comments,
   docstrings and string literals can never match. Fails closed
   (`_fatal`) if the source cannot be read or parsed. Standard library
   only.
3. `preflight()` now iterates `_RANDOMNESS_GUARDED_SOURCES` and calls the
   helper; a non-empty result is fatal
   (`"<fname> imports a randomness module: [...]"`). The guard keeps its
   original position in `preflight()` — before any trajectory.
